A full-stack web application developed using the MERN stack (MongoDB, Express.js, React.js, and Node.js) to simplify vehicle rentals. The system allows users to browse available vehicles, book vehicles online, and track booking status, while administrators can manage vehicles and customer bookings.

📌 Project Overview

The Vehicle Rental Management System provides a centralized platform for managing vehicle rentals. It includes separate user and administrator functionalities to make vehicle booking and management easier.

Features : 

👤 User Module

* User Registration & Login – Create an account and log in securely.
* Browse Vehicles – View available vehicles and their details.
* Vehicle Categories – Explore sedans, SUVs, luxury cars, bikes, sports vehicles, and electric vehicles.
* Online Booking – Book a vehicle by entering pickup and drop-off details.
* Booking Details – Provide contact information and driving licence details.
* Driver Option – Request a driver for an additional charge.
* Price Calculation – Calculate the estimated rental price based on rental duration and driver charges.
* My Bookings – View personal booking details.
* Booking Status – Track whether a booking is pending, accepted, or rejected by the administrator.

🔐 Admin Module

* Admin Login – Access the administrative dashboard.
* Vehicle Management – Add, view, update, and delete vehicle details.
* Vehicle Information – Manage vehicle names, categories, prices, seats, fuel types, images, and availability.
* Customer Bookings – View customer booking requests.
* Booking Management – Accept or reject booking requests.
* Booking Status Updates – Update booking status so users can see the latest decision.
